# Freekick — Любительська онлайн-гра "Пенальті" з аніме-персонажами (PC / Unity C#)

Багатокористувацька онлайн-гра для ПК (дуель 1 на 1 у форматі серії післяматчевих пенальті) з каталогом персонажів із популярних аніме-тайтлів, системою облікових записів, таблицею лідерів для друзів та базовими механізмами захисту даних.

Проект розробляється як **любительська гра для особистого користування та спільних матчів з друзями** в рамках лабораторної роботи з дисципліни **«Безпека програм та даних» (Program Security Lab 2026)**.

---

## 🎮 Концепція та ключові особливості

1. **Цільова платформа та рушій:** Десктопна гра під **PC (Windows)**, розроблена на рушії **Unity (C#)** без перевантаження складними enterprise-технологіями.
2. **Мережева гра для особистого користування:** Можливість грати з друзями по локальній мережі (LAN) або через інтернет (за прямим IP / кодом кімнати / віртуальною мережею) за допомогою легкого C# мережевого коду (Unity Netcode / легкий сокетний сервер).
3. **Реєстрація та захист облікових даних:** Проста реєстрація за поштою та унікальним нікнеймом, надійне криптографічне хешування паролів (Argon2id / PBKDF2) з індивідуальною сіллю.
4. **Профіль та каталог аніме-героїв:** Віджет профілю у правому верхньому куті екрана. Можливість відкрити каталог франшиз («Blue Lock», «Captain Tsubasa», «Inazuma Eleven» тощо), розгорнути список героїв та вибрати свого улюбленого персонажа.
5. **Ігровий процес 1v1:**
   - Криптографічне жеребкування першого удару (CSPRNG).
   - По черзі по 1 удару кожним гравцем.
   - **Суворе правило 5 обов'язкових раундів (10 ударів сумарно):** кожен гравець обов'язково пробиває рівно 5 ударів, навіть якщо математичний переможець визначився раніше — це необхідно для чесного обліку забитих та пропущених голів.
   - Механіка 3 напрямків: гравець і воротар обирають `LEFT`, `CENTER` або `RIGHT`. Збіг — сейв воротаря, розбіжність — гол.
   - Підтримка результату **нічиєї (`DRAW`)**: якщо після 10 ударів рахунок рівний, фіксується бойова нічия, обидва гравці отримують по +1 очку в таблицю.
6. **Захист від сніфінгу (Anti-Sniffing Commit-Reveal):** Сервер/хост фіксує ходи приховано — жоден гравець не може перехопити вибір суперника через Wireshark або мережеві пакети до моменту розкриття обох рішень.
7. **Таблиця лідерів та захист збережень:** Ведення статистики дуелей між друзями (перемоги, поразки, нічиї, забиті/пропущені голи) із захистом локальних даних від ручного редагування в блокноті через перевірочний хеш цілісності (HMAC-SHA256).
