# Freekick — Онлайн-гра "Пенальті" з аніме-персонажами

Багатокористувацька онлайн-гра (1v1 серія післяматчевих пенальті) з системою облікових записів, каталогом аніме-персонажів з популярних тайтлів, глобальною таблицею лідерів та підвищеними стандартами криптографічного захисту.

Проект виконується в рамках лабораторної роботи з дисципліни **«Безпека програм та даних» (Program Security Lab 2026)**.

## 🎮 Короткий огляд функціоналу

1. **Реєстрація та безпека:** пошта, унікальний нікнейм (без урахування регістру), хешування паролів за стандартом **Argon2id** з індивідуальною сіллю.
2. **Профіль та вибір героя:** віджет у правому верхньому куті, каталог аніме-тайтлів («Blue Lock», «Captain Tsubasa», «Inazuma Eleven» тощо) з розгортанням персонажів і можливістю зміни активного героя.
3. **Ігровий процес 1v1:** жеребкування першого удару (CSPRNG), по черзі по 1 удару кожним гравцем, 5 обов'язкових раундів (10 ударів сумарно), вибір одного з трьох напрямків (`LEFT`, `CENTER`, `RIGHT`).
4. **Захист від сніфінгу:** одночасний прихований ввід напрямків (Commit-Reveal) — клієнт не може підглянути вибір суперника.
5. **Глобальний лідерборд:** відкрита таблиця лідерів із рейтингом перемог, забитих та пропущених голів.
