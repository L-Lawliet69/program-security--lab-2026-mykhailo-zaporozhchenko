# Changelog — Identity Module

## [2026-10-03] [DOCS-001] Початкова специфікація безпеки облікових записів
- Описано сутності `UserAccount` та `Profile`.
- Зафіксовано обов'язкове використання криптографічного алгоритму Argon2id для хешування паролів.
- Впроваджено сувору перевірку унікальності нікнеймів без урахування регістру (`UniqueNicknameDPolicy`).
- Визначено механізм захисту від атак типу брутфорс та правила складності паролів.
