# Журнал змін (Changelog) — Identity Module

## [2026-10-12] [OOP-001] Спрощення архітектури та перехід на C# ООП для Unity
- Повністю вилучено Domain-Driven Design (DDD): прибрано Aggregate Root `UserAccount`, доменні політики `UniqueNicknameDPolicy`, `PasswordComplexityDPolicy` та доменні події.
- Запроваджено простий C# клас `PlayerProfile` та сервіс `AuthService`.
- Збережено обов'язкові вимоги безпеки для лабораторної роботи: надійне хешування паролів (Argon2id/PBKDF2) з сіллю, унікальність нікнеймів без урахування регістру та захист від таймінг-атак.

## [2026-10-03] [DOCS-001] Початкова специфікація безпеки облікових записів
- Описано базові правила реєстрації та вимоги до паролів.
