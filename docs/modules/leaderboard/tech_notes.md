# Технічні нотатки — Leaderboard Module (Unity C#)

## Технічні деталі та безпека збережень

### 1. Захист файлу збереження від ручного редагування (HMAC-SHA256)
- **Проблема (актуальна для лаби):** Якщо таблиця результатів або збереження гравця знаходиться у звичайному текстовому `leaderboard.json`, будь-який гравець може відкрити його через `Notepad.exe` і прописати собі 999 перемог.
- **Рішення:**
  1. При збереженні файлу дані серіалізуються в JSON.
  2. Обчислюється контрольний хеш: `HMACSHA256(jsonBytes, secretKey)`.
  3. Підпис зберігається разом із файлом (у заголовку або окремому файлі `leaderboard.sig`).
  4. При завантаженні гри підпис перевіряється заново. Якщо вміст файлу було змінено в блокноті, перевірка не проходить, гра видає повідомлення про порушення цілісності та блокує невалідні результати.

### 2. Сортування та продуктивність
- Оскільки гра розроблена для особистого користування з друзями (кількість записів зазвичай десятки або сотні, а не мільйони), сортування через C# LINQ `OrderByDescending().ThenByDescending()` виконується за лічені мілісекунди без потреби у важких базах даних типу Redis.
