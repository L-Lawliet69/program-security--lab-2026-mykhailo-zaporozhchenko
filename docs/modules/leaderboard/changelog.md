# Журнал змін (Changelog) — Leaderboard Module

## [2026-10-12] [OOP-001] Спрощення архітектури та перехід на C# ООП для Unity
- Повністю вилучено Domain-Driven Design (DDD): прибрано Aggregate Root `LeaderboardEntry`, доменні івенти та зовнішні брокери.
- Запроваджено простий C# клас `LeaderboardEntry` та сервіс `LeaderboardService`.
- Замінено Redis/PostgreSQL на збереження у локальний файл/SQLite з перевірочним підписом HMAC-SHA256 (захист від редагування в блокноті).

## [2026-10-03] [DOCS-001] Початкова специфікація таблиці лідерів
- Описано поля статистики (перемоги, поразки, нічиї, голи) та формулу очок ($3 \times W + 1 \times D$).
