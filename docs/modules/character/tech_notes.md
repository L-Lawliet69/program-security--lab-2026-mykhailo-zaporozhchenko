# Технічні нотатки — Character Module (Unity C#)

## Організація ресурсів у Unity

1. **Зберігання та завантаження спрайтів:**
   - Спрайти персонажів та іконки розміщуються у папці `Assets/Resources/Sprites/Characters/` або налаштовуються як `ScriptableObject` префаби.
   - Завантаження ассету за потреби: `Resources.Load<Sprite>(character.SpriteResourcePath)`.
2. **Локальна конфігурація:**
   - Список персонажів та тайтлів формується у статичному файлі `characters.json` або у вигляді Unity Scriptable Objects, що не потребує мережевих запитів під час запуску гри.
3. **Гарантія дефолтного персонажа:**
   - Якщо у гравця з якихось причин не обраний персонаж або файл сейву пошкоджено, система автоматично підставляє `isDefault = true` персонажа (Ісагі Йоічі), що унеможливлює появу `NullReferenceException` у вікні матчу.
