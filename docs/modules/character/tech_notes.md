# Technical Notes — Character Module

## Особливості реалізації

1. **Кешування каталогу:** Каталог тайтлів і персонажів є статичним або рідко змінюваним ресурсом. Доцільно кешувати повний каталог у Redis (TTL 24 години) або локально на клієнті, інвалідуючи кеш за подією оновлення каталогу.
2. **Безпека ассетів:** Посилання на аватарки та анімації мають зберігатися на захищеному CDN із перевіркою MIME-типів (`image/webp`, `image/png`, `video/webm`) для унеможливлення завантаження шкідливих файлів при адмініструванні.
3. **Дефолтне значення:** При першій реєстрації гравця йому автоматично призначається `default_character_id` із конфігурації платформи, що виключає стан відсутності персонажа (`NULL-less` принцип).
